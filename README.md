# runner_ip2bing

A simple Python script that takes an IP address as input and opens a Bing search query for `ip:<IP_ADDRESS>` in your default web browser.

## Usage

Run the script from your terminal, providing the IP address you want to search for as a command-line argument:

```bash
python app.py <IP_ADDRESS>
```

**Example:**

```bash
python app.py 8.8.8.8
```

This will open your default web browser to a Bing search results page for `ip:8.8.8.8`.
